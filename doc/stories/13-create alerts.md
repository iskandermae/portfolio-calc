# Story: Create alerts

## Description
Develop the functionality to issue price alerts for selected securities buy the criteria:
- x% lower than historicaly max price
- x% higher/lower then the last buy (can be run for all securities in the portfolio)
- x% higher then fixed price for this security

## Acceptance Criteria
- [ ] User can add/remove the rules.
- [ ] Application has the UI to evaluate the rules and highlight the alerts .
- [ ] Application has a command line parameter to be run without UI, evaluate the rules and send alerts in a chat of a messenger (telegram/other messenger that has easy to implement interface).
