Requirements
Build a C# application to calculate my portfolio performance. 
Keep clear code segregation: GUI, application, core layers, data interaction (disc, internet queries, ...) - all should be segregated in separate modules/projects

The scope for the MVP:
- local data storage of the transactions (both cash and security transactions)
- import of transactions from a file, exported from IBKR
- fetching cross-currencies (could be different websites/APIs for different currencies)
- imported cross-currencies, prices should be stored locally and reused
- setting to choose the base currency
- import of inflation rates per month/year for the base currency (on calculation demand)
- database should be local, no need to install/maintain but reliable
- separate functionality to check the quality of imported cross-currencies and prices. If the value has been changed very rapidly – it should be shown for manual validation and used from the cash/storage only after it is marked as valid. So the main screen should have status messages if some manual process is required.
- report/window with the list of transactions with sorting by fields. The sorting/layout should be automatically saved for future re-use
- report of the current portfolio value with the breakdown by the positions (securities) in security currency and total in base currency
- report for the selected position/(other security, not from my portfolio) with the chart of the position value with the inflation considered
- report for the selected position – with current price, all dividends, all expenses with the inflation considered – all figures and synthetic average yearly growth rate ( solving the equation [current price] = [init price] * [1 + rate]^n , the equation should be adopted to calculate on days basis and converted to annual rate). Inflation – should be an option in the UI
- additional useful reports to provide information on portfolio performance
- list of favorite shares/bonds/etf(s) to be able to quickly trigger reports and do regular analysis
